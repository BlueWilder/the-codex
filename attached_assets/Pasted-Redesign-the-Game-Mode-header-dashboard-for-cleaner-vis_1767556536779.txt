Redesign the Game Mode header/dashboard for cleaner visual hierarchy and better UX.

## 1. HEADER ROW

Single row with script selector and day tracker:

┌─────────────────────────────────────────┐
│ 📜 New Test Script ▼       ☀️ Day 2 ⬆⬇  │
└─────────────────────────────────────────┘

- Script selector on left (dropdown)
- Day tracker on right with subtle up/down arrows (not large buttons)
- Remove "End Game" from here (move to overflow menu)

## 2. STATS GRID

2x2 card grid for primary stats:

┌───────────────────┬─────────────────────┐
│                   │                     │
│   👤 15           │    💀 1 (0👻)       │
│   Alive           │    Dead             │
│                   │                     │
├───────────────────┼─────────────────────┤
│                   │                     │
│   ⚖️ 8            │    ✋ 15            │
│   To Exec         │    Can Vote         │
│                   │                     │
└───────────────────┴─────────────────────┘

### Styling:
- Each stat is a card with subtle border or background
- Large number, small label below
- Icon + number on same line, label below
- Alive = green/teal number
- Dead = red number
- Ghost count integrated: "1 (2👻)" means 1 dead, 2 ghost votes remaining
- When ghost votes are spent, show: "3 (0👻)" or just "3" with no ghost indicator

### Ghost Vote Display Logic:
- Show "(X👻)" where X = dead players with ghostVoteSpent: false
- If all ghost votes spent, show "(0👻)" or hide ghost indicator entirely
- Format: "💀 3 (2👻)" = 3 dead, 2 can still vote

## 3. TRAVELER ROW (Conditional)

Only display this row if Travelers exist in the game:

┌─────────────────────────────────────────┐

└─────────────────────────────────────────┘

- Show: [active] / [total] Travelers
- Parenthetical for exiled/left count if any

- Subtle styling - less prominent than main stats

## 4. TAB NAVIGATION (Replaces Toggle Buttons)

Replace the [List] [Circle] [Log] toggle buttons with a proper tab bar:

┌─────────────────────────────────────────┐
│    List    │   Circle    │    Log      │
└─────────────────────────────────────────┘

### Tab Styling:
- Full-width tab bar
- Active tab: Highlighted background, bold text, or underline indicator
- Inactive tabs: Muted text
- Equal width for each tab
- Tapping switches content below

### Tab Content:
- List tab → Player list (current default view)
- Circle tab → Seating chart circle view
- Log tab → Game log (can be inline instead of modal now)

**Important:** Making Log a tab instead of modal means the log displays in the main content area, not as an overlay. This is cleaner for reviewing during play.

## 6. END GAME PLACEMENT

Remove "End Game" from the main UI. Add it to:

### Option A: Overflow Menu
Add a ⋮ (three dots) icon in the header row:

┌─────────────────────────────────────────┐
│ 📜 New Test Script ▼    ☀️ Day 2 ⬆⬇  [⋮]│
└─────────────────────────────────────────┘

Tapping ⋮ shows menu:
- End Game
- Reset Day Counter
- Clear All Data
- (Future: Export Game)

### Option B: In Log Tab
Add "End Game" button at the bottom of the Log view:
- Log is where you'd review the game anyway
- Natural place to conclude

### Option C: Long-press Day Counter
Long-press on "Day 2" reveals End Game option
- Hidden but discoverable
- Prevents accidental taps

**Recommendation:** Option A (overflow menu) - most intuitive
