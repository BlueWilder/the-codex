## Official BOTC JSON format (from script.bloodontheclocktower.com)
The exported JSON is an array. Structure:
- First element is a metadata object: { "id": "_meta", "name": "Script Name", "author": "Author Name" }
- Remaining elements are character objects: { "id": "characterid" } where id is lowercase alphanumeric (e.g. "washerwoman", "imp", "fanggu")
- Some exports omit the _meta object entirely — handle both cases

Example:
[
  { "id": "_meta", "name": "My Script", "author": "Brad" },
  { "id": "washerwoman" },
  { "id": "librarian" },
  { "id": "imp" }
]

## Task
Add JSON import to the custom script editor. Allow users to paste or upload a JSON file exported from the official BOTC Script Tool and have it populate the script editor fields.

## Step 1 — Audit
Open the custom script editor component. Identify:
- How characters are currently added/stored in the editor state
- How the script name field is bound
- Whether a file input or paste area already exists anywhere in the editor
Stop and show me the editor component structure before proceeding.

## Step 2 — Import UI
Add an "Import JSON" button to the custom script editor, placed above the character selection area.
Clicking it opens a modal or inline panel (use whichever pattern already exists in the app) with two options:
- "Paste JSON" — a textarea where the user can paste JSON text
- "Upload File" — a standard file input accepting .json files only
Include a "Import" confirm button and a "Cancel" button.
Do NOT build a new modal component if one already exists — reuse it.

## Step 3 — Parse & validate
On import:
1. Parse the JSON — show a clear inline error if it is not valid JSON
2. Check for the _meta object — if present, pre-fill the script name field with _meta.name
3. Extract all character id values (excluding "_meta")
4. Match each id against the existing character data in game-data.ts using the character's id field
5. For each matched character, add it to the editor's selected characters state
6. For any unrecognized ids, collect them and show a warning list: "X characters not recognized and were skipped: [list of ids]" — do not block the import
7. If zero characters matched, show an error and do not proceed

## Step 4 — Post-import state
After a successful import:
- Script name field: populated from _meta.name if present, otherwise left as current value
- Character selection: replaced with the imported characters
- Synopsis field: left blank (user can fill in manually)
- Editor remains open — user can review and edit before saving
- Show a success message: "[X] characters imported from [script name]"
