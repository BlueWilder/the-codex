| 🌙 | Night marker |

## 5. TIMESTAMPS / ORDERING

### Option A: Use entry order (simpler)
Events display in the order they were recorded within each day.

### Option B: Add timestamps (more accurate)
When recording claims, nominations, deaths - store a timestamp.
Sort events by timestamp within each day.

**Recommendation:** Start with Option A. Entry order is usually close to actual order since users record things as they happen.

## 6. DAY/NIGHT SECTIONS

### Day Sections:
- All nominations
- All claims made during that day
- Executions
- Traveler exiles
- Ghost votes used (on executions)

### Night Sections:
- Deaths that occurred overnight
- Travelers who joined/left at night (rare)

### Determining Night Deaths:
Currently, "Mark as Dead" doesn't distinguish execution vs night death.

For now:
- If player died AND was executed that day → Show under Day as "EXECUTED"
- If player died AND was NOT executed → Show under Night as "died"

Future enhancement: Explicit night death tracking.

## 7. FILTERING (Optional Enhancement)

Add filter toggles at top of log:
- [All] [Claims] [Nominations] [Deaths] [Travelers]

Default: All events shown.

## 8. EMPTY STATE

If game just started with no events:
"No events recorded yet. Start tracking claims and nominations!"

## 9. STYLING

- Match the grimoire/gothic theme
- Day headers: Prominent, maybe gold/amber color
- Night headers: Subtle, maybe purple/dark blue
- Events: Clean list with icons
- Scrollable for long games
- Read-only (no editing from this view)
