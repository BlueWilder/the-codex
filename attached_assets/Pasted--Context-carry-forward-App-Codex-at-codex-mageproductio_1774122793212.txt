### ST Step 3 — Bag Builder
This is the new screen. Layout:

**Header:** Script name · Player count · Required breakdown (e.g. "5 Townsfolk · 1 Outsider · 1 Minion · 1 Demon")

**Character grid:** Display all characters on the selected script grouped by type (Townsfolk, Outsiders, Minions, Demons). Each character card shows name + ability text (short form). Cards are selectable — clicking toggles a LOCKED state (visually distinct, e.g. gold border or lock icon).

**Running tally:** Live counter showing how many of each type are currently selected vs required. Tally turns green when a type is exactly filled, red if over, neutral if under.

**Shuffle button:** Randomizes all UNLOCKED slots to fill the remaining required count per type. Locked characters stay fixed. If locked selections already exceed the required count for a type, show an error state on that type's tally — do not auto-remove locked characters.

**Reshuffle button:** Re-randomizes only the unlocked characters without changing locked ones.

**Clear locks button:** Removes all locks, resets to unselected state.

**Accept Bag button:** Active only when tally is exactly met for all types. Advances to ST Step 4.

### ST Step 4 — Night Sheets
Display two tabs: "First Night" and "Other Nights"
Each tab shows an ordered list of characters that act on that night, in official night order as defined in game-data.ts.
Show only characters present in the finalized bag.
Each row: character name · ability reminder text · type badge (color-coded).
No print/PDF needed — screen display only.
Include a "Start Game" button that enters the existing game session using the finalized bag and player count. Player names default to "Player 1", "Player 2" etc. (skip the player name entry step for ST mode).
