Add a "Play Again" option that starts a new game while keeping the same player names.

## CONCEPT

After a game ends (or mid-game if needed), users can quickly start a fresh game with the same group of players. This resets all game data except player names and count.

## 1. PLACEMENT

Add "Play Again" option in the overflow menu (⋮):

┌─────────────────────┐
│ Play Again          │  ← NEW
│ End Game            │
│ Reset Day Counter   │
│ Clear All Data      │
└─────────────────────┘

## 2. PLAY AGAIN BEHAVIOR

When "Play Again" is tapped:

### Show Confirmation Dialog:
"Start a new game with the same players?

This will reset:
• All nominations and votes
• All claims
• All deaths
• Day counter
• Game notes
• Traveler status

Player names will be kept.

[Cancel]  [Play Again]"

### On Confirm - RESET:
- currentDay → 1
- gameNotes → ""
- All players:
  - isAlive → true
  - claims → []
  - notes → ""
  - votes → []
  - nominationHistory → []
  - ghostVoteSpent → false

### On Confirm - KEEP:
- Player names
- Player count
- Player order (seating arrangement)
- Script selection

### On Confirm - HANDLE TRAVELERS:
Option A: Remove all Travelers (they were game-specific)
Option B: Keep Travelers but reset their status
Option C: Ask user "Keep Travelers?" 

**Recommendation:** Option A - Remove Travelers. They typically change between games. User can re-add if needed.

## 3. ALTERNATIVE PLACEMENT - End Game Flow

When user taps "End Game", show options:

┌─────────────────────────────────────────┐
│ End Game                                │
├─────────────────────────────────────────┤
│ What would you like to do?              │
│                                         │
│ [🔄 Play Again]                         │
│ Start new game with same players        │
│                                         │
│ [🚪 Exit to Setup]                      │
│ Return to game setup screen             │
│                                         │
│ [Cancel]                                │
└─────────────────────────────────────────┘

This makes "Play Again" discoverable at the natural end-of-game moment.

## 4. OPTIONAL: QUICK ACCESS

If running tournaments or back-to-back games, consider adding a more visible button:

### Option A: In Log tab footer
After Game Notes section:
[🔄 Play Again]  [🚪 End Game]

### Option B: In stats panel (when game seems "over")
If only 2-3 players alive, subtly show "Game ending? [Play Again]"

## 5. DATA STRUCTURE

No new fields needed. Just a reset function:

```typescript
function playAgain(game: Game): Game {
  return {
    ...game,
    currentDay: 1,
    gameNotes: "",
    players: game.players
      .filter(p => !p.isTraveler)  // Remove Travelers
      .map(p => ({
        ...p,
        isAlive: true,
        claims: [],
        notes: "",
        votes: [],
        nominationHistory: [],
        ghostVoteSpent: false,
      })),
  };
}
