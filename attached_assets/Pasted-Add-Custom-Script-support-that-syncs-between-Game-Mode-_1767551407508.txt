Add Custom Script support that syncs between Game Mode and Character Reference.

## CONCEPT
Users can create a custom script by selecting specific characters. This custom script:
- Applies to Game Mode (claims picker, game setup)
- Applies to Reference page (character filter)
- Persists until cleared or replaced
- Syncs automatically between both views

## 1. SHARED STATE

Create a shared custom script state (localStorage or app state):

interface CustomScript {
  id: 'custom';
  name: string; // User-defined name, default "Custom Script"
  characters: string[]; // Array of character IDs
  createdAt: Date;
}

This state is accessible from both Game Mode and Reference page.

Current dropdown shows:

Update to:

### When "Custom Script" is selected:

**If no custom script exists:**
- Open the Custom Script Builder (see section 4)

**If custom script already exists:**
- Apply it immediately
- Show script name in selector: "Custom: [Script Name]"
- Add an "Edit" button or icon next to the selector to modify

## 3. REFERENCE PAGE - FILTER INTEGRATION

Current filters likely include:
- All Characters
- Trouble Brewing
- Bad Moon Rising
- Sects & Violets
- (By team filters)

Update to include:
- **Custom Script** option (only visible if a custom script exists)
- When selected, shows only characters in the custom script + all Travelers

### Sync Behavior:
- If user creates/edits custom script in Game Mode → Reference filter updates automatically
- If user creates/edits custom script in Reference → Game Mode filter updates automatically
- Changes are instant (shared state)
